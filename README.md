# Егор Кузьмичев

Архив текстов Егора Кузьмича Кузьмичева.

- [`completeworks/`](completeworks) — полное собрание сочинений: стихи, рассказы, публицистика
- [`verses/`](verses) — книга стихов
- [`letters/`](letters) — письма с комментариями и справками о персоналиях

Каталоги `verses/` и `letters/` раньше были отдельными репозиториями
(`aeifn/verses`, `aeifn/letters`); их история сохранена.

## Сборка

Тексты набраны в [Typst](https://typst.app). Нужен `typst` версии 0.14 или новее.

```sh
make              # все три книги
make verses       # verses/book/book.pdf
make completeworks
make letters
make watch BOOK=letters   # пересборка при каждом изменении
```

Общее оформление — в [`template/archive.typ`](template/archive.typ):
формат 145×205 мм, шрифт Old Standard TT (лежит в `template/fonts/`,
лицензия OFL), фотографии — в `template/images/`.

## Разметка стихов

```typst
#poem(title: [Дорогое детство], alt: true, date: [1904])[
  Люблю я детство золотое,\
  В родной деревне прожитое,\

  Вторая строфа — после пустой строки.
]
```

- строки заканчиваются на `\`, строфы разделяются пустой строкой;
- `#vin` в начале строки — дополнительный отступ;
- `alt: true` — отступ у каждой второй строки;
- `pattern: (0, 0, 1)` — отступы строк в строфе по образцу, `cycle: true` — образец повторяется;
- без `title` стихотворение печатается под «* * *», а в содержание идет `toc`;
- также есть `dedication`, `source`, `signature`, `date`, `note`.

Комментарии редакторов (`// …`) сохранены из LaTeX-версии.
